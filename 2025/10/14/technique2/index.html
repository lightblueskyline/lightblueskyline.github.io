Windows11 共享 WiFi 網絡給路由器

  1. Windows 開啓 WLAN 共享

    • Win + R 打開運行，輸入 ncpa.cpl 並回車，打開網絡連接窗口。
    • 右鍵點擊 WLAN 網絡，選擇 “屬性”。
    • 切換到 “共享” 標籤，勾選 “允許其他網絡用戶通過此計算機的 Internet 連接來連接”。
    • 在 “家庭網絡連接” 下拉菜單中，選擇你想要共享的網絡連接 (通常是以太網或其他網絡接口)。
    • 點擊 “確定” 保存設置。

  2. 使用網綫連接路由器的 WAN 口和電腦的有綫網絡接口

  3. 設置路由器

    • 登錄路由器管理界面，通常是通過瀏覽器訪問
    • 設置路由器的 WAN 口爲自動獲取 IP 地址 (DHCP)。
    • 保存設置並重啓路由器。

  4. 連接測試

    • 確保路由器成功獲取到來自 Windows 的 IP 地址。
    • 使用連接到路由器的設備測試網絡連接，確保可以訪問互聯網。

  5. 注意事項

    • 確保 Windows 設備保持開啓狀態，否則路由器將無法訪問互聯網。
    • 根據需要調整防火牆設置，以允許網絡共享。
    • 如果遇到問題，可以嘗試重新啓動 Windows 設備和路由器。

  6. 配置靜態路由，以提供共享網絡的電腦可以訪問接入路由器的設配

    • 在 Windows 設備上打開命令提示符 (以管理員身份運行)。

    • 使用 ipconfig 命令查看 Windows IP 配置。

    • 使用命令 arp -a 查看路由器的 IP 地址和 MAC 地址。

    • 在列表中查找 192.168.137.x 的地址，這通常是 Windows 共享網絡的默認網段。

    • 記下路由器的 IP 地址 (例如 192.168.137.123)。
